Engångssetup (gör detta innan sidan fungerar)
1. Öppna den här filens kod och hitta konstanterna högst upp i scriptet (sök efter "FYLL I").
2. Sätt owner till ditt GitHub-användarnamn och repo till repots namn.
3. Skapa en token: github.com → din profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Begränsa den till endast detta repo, och ge den behörigheten Contents: Read and write (inget annat behövs).
4. Klistra in ungefär första halvan av token i TOKEN_PART_A och resten i TOKEN_PART_B (den är delad i koden så GitHubs egen säkerhetsskanning inte blockerar uppladdningen).
5. Spara filen och ladda upp den till samma repo, gärna med ett svårgissat filnamn (t.ex. facit-admin-x7k2.html) eftersom det är just adressen som skyddar sidan.
6. Klart — öppna din nya hemliga adress, redigera, och tryck "Spara facit till GitHub".

Om GitHub fortfarande blockerar uppladdningen ("secret detected"): gå till repots Settings → Code security and analysis → stäng av "Push protection" (och "Secret scanning" om den är på) för just det här repot, och försök igen.
